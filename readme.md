## Description of Completed Exercises

This project contains simple Python exercises completed in the `python_labs` folder.

Completed programs:

- `calculator.py`: basic arithmetic operations
- `even_odd.py`: checks if a number is even or odd
- `grade_calculator.py`: calculates a grade based on score input
- `multiplication_table.py`: prints a multiplication table
- `todo_list.py`: manages a simple to-do list

## How to Run the Programs

1. Open a terminal or command prompt.
2. Navigate to the `python_labs` folder.
3. Run a program with Python, for example:

```bash
python calculator.py
```

Replace `calculator.py` with the desired script name.
